# BriZ-BarZ
BriZ BarZ (Breezy Bars) is a Candy Crush-style word puzzle game built around rap lyricis.Words fall onto the board, and players connect rhyming words to create combos. Simple rhymes earn fewer points,  AI evaluates originality, rhyme, wordplay, flow, and lyrical devices such as metaphors, similes, internal rhymes, and multisyllabic rhymes.
